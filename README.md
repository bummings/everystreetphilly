# Every Street Philly — GitHub Pages upload

Upload the *contents* of this folder to the publishing branch/folder of a GitHub Pages repository. Keep the `data` folder beside `index.html`; it contains the route archive, street-scorecard data, and Philadelphia boundary required by the map.

GitHub Pages will serve this static site without a build step. The map uses online MapLibre, Google Fonts, and OpenStreetMap map tiles for its background, so the interactive basemap needs an internet connection. The completed/remaining scorecard data itself is included locally in this folder.
